# GMM Group of Industries — Sovereign Corporate Holding Portal

![GMM Group of Industries Logo](./public/gmm-logo.svg)

An architectural, minimalist corporate holding portal for **GMM Group of Industries**, engineered to project generational stability, institutional scale, and boardroom gravitas.

## 🏛️ Conglomerate Architecture & Ecosystem

GMM Group of Industries serves as the apex parent holding enterprise governing eight specialized market leaders across four core industrial verticals:

### 1. Heavy Engineering & Fabrication
- **GMM Heavy Engineering Ltd.** (Est. 1988) — High-precision industrial steel fabrication, ASME pressure vessels, boiler structures, and mega-bridge girders.
- **GMM Structural Casting & Metallurgy** (Est. 1996) — Continuous induction billet casting, ladle metallurgy refining, and seismic 500W/550D TMT rebar.

### 2. Energy, Power & Marine Infrastructure
- **GMM Power & Energy Infrastructure** (Est. 2004) — Utility-scale 132/33 kV substation engineering, power transformers up to 50 MVA, and hybrid industrial microgrids.
- **GMM Infra & Marine Construction** (Est. 2009) — Deep-water dredging, jetty construction, pre-stressed tubular piling, and coastal river training.

### 3. Maritime Logistics & Supply Chain
- **GMM Global Maritime & Shipping** (Est. 2011) — Commercial dry-bulk shipping fleet, ocean Supramax freight operations, and coastal feeder networks.
- **GMM Integrated Logistics & Terminals** (Est. 2016) — 50-acre bonded inland container depot (ICD), automated dry ports, and multi-temperature cold chain logistics.

### 4. Advanced Materials & Refineries
- **GMM Poly-Plast & Advanced Materials** (Est. 2014) — Engineered non-woven geo-textiles, industrial polypropylene packaging, and circular polymer recycling.
- **GMM Agro-Tech & Commodity Refineries** (Est. 2019) — Automated grain silo complexes (200,000 MT), Bühler milling lines, and continuous edible oil fractional distillation.

## 🌐 Features

- **Architectural Minimalism**: Editorial layout with 1px hairline dividers, deep obsidian accents, and surgical flame-vermilion (`#FC5812`) highlights.
- **Instant Bilingual Switching**: Real-time state-driven switch between **English** and **বাংলা** (Bengali) with typography matching (`Plus Jakarta Sans` & `Hind Siliguri`).
- **Interactive Subsidiary Explorer**: Bento-grid layout with sector filtering and deep-dive executive dossier modal dialogs.
- **Corporate Governance & ESG**: Boardroom ethics, statutory disclosures, and environmental zero-discharge roadmap.
- **Ultra-Responsive**: Fully optimized for PC multi-column displays and mobile handheld devices.

---

## 🚀 Technology Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom corporate design tokens
- **Icons**: Lucide React (1.25px stroke width)
- **Deployment**: Vercel Production + GitHub CI/CD

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/gmmgroupofindustries/gmm-holding-portal.git

# Enter project directory
cd gmm-holding-portal

# Install dependencies
npm install

# Start local development server
npm run dev
```
